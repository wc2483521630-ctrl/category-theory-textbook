# 范畴论 · 逻辑 · 拓扑斯：三书递进自学教材

一套面向数学哲学方向的自学讲义，以三本著作为主线递进展开：

1. **Awodey — *Category Theory*（2nd ed.）**：范畴、函子、自然变换、极限、指数对象、Yoneda、伴随与 Monad。
2. **Lambek & Scott — *Introduction to Higher Order Categorical Logic***：演绎系统、笛卡尔闭范畴、λ-演算、证明同一性、类型论、拓扑斯与完备性。
3. **Mac Lane & Moerdijk — *Sheaves in Geometry and Logic***：函子范畴、层、Grothendieck 拓扑、拓扑斯、几何态射、局部性拓扑斯与几何逻辑。

全书 21 章 / 93 节，已全部生成完毕。第 21 章为终章。

## 阅读方式

直接用浏览器打开总目录 HTML，从中跳转到各章。每节固定四块结构：

1. **学习目标**
2. **正文讲授**：定义、定理与完整证明，标注对应原书章节
3. **习题**：基础巩固 + 进阶思考
4. **完整参考答案**

哲学联系统一放在「选读拓展」区块，与数学正文分离。公式由 MathJax（CDN）渲染，首次打开需联网加载。
