附录 A　米田引理 · 全局交换图

本附录只做一件事：把米田引理涉及的全部对象、态射、自然变换与复合关系画进一张完整交换图，并以分步动画依次显现。文字证明已在第 6 章 §6.4，此处不再重复推导。

怎么看这张图

页面打开后动画自动播放：先出现范畴 C 与它的箭头，再长出 Set 中的两列对象与函子作用，随后 η 的分量把两列连成三个交换方块，最后选出关键元素 \(x=\eta_C(\mathrm{id}_C)\) 并给出米田双射与 corner 构造。三个方块会依次闪烁，演示"两条路径相等"的交换关系。刷新页面可重播，或点下方按钮。

图注：每个节点与箭头的含义

节点（左）　\(C,C',C''\) 是范畴 \(\mathbf C\) 的三个对象；\(f:C o C'\)、\(g:C' o C''\)、\(g\circ f:C o C''\) 是它们之间的箭头。

节点（中·蓝列）　\(\operatorname{Hom}(C,C),\operatorname{Hom}(C,C'),\operatorname{Hom}(C,C'')\) 是表示函子 \(H=\operatorname{Hom}(C,-)\) 在三个对象上的值；其中标红的 \(\mathrm{id}_C\) 是恒等箭头，\(f\) 是 corner。

节点（中·绿列）　\(F(C),F(C'),F(C'')\) 是函子 \(F:\mathbf C o\mathbf{Set}\) 在对象上的值；标红的 \(x=\eta_C(\mathrm{id}_C)\in F(C)\) 是米田对应选出的元素。

节点（右·紫框）　\(\operatorname{Nat}(\operatorname{Hom}(C,-),F)\) 与 \(F(C) i x\) 是米田双射 \(\cong\) 的两端。

蓝色竖直箭头　\(H(f),H(g),H(g\circ f)\)（即 \(e(C,f)\) 等）是 hom 函子对箭头的作用——后复合。

绿色竖直箭头　\(F(f),F(g),F(g\circ f)\) 是函子 \(F\) 对箭头的作用。

紫色水平箭头　\(\eta_C,\eta_{C'},\eta_{C''}\) 是自然变换 \(\eta:H\Rightarrow F\) 在三个对象处的分量。

黄色方块　三个自然性方块（\(g\circ f\) 为虚线大框）：因 \(\eta\) 是自然变换，方块两路相等，例如 \(\eta_{C'}\circ H(f)=F(f)\circ\eta_C\)，在 \(\mathrm{id}_C\) 上取值即得 \(\eta_{C'}(f)=F(f)(x)\)。

红色双向箭头　\(\Phi:\eta\mapsto\eta_C(\mathrm{id}_C)=x\) 与 \(\Psi:x\mapsto\eta^x\)（corner 构造 \(\eta^x_B(f)=F(f)(x)\)）互为逆，给出双射；下方注明取 \(F=\operatorname{Hom}(-,B)\) 时它 specialize 成 Yoneda 嵌入（unit）的满忠实性。

交互版：可点击下钻的嵌套交换图

下图顶层是米田引理全局交换图。点击三个金色虚线节点（Hom 函子 / corner 构造 / unit 嵌入）可进入对应子交换图，子图左上角的「← 返回总图」可回到顶层。右上角 + / − / ⟲ 用于无损缩放与复位；也可直接在图上放大查看箭头与态射。脚本内嵌于 SVG，无外部依赖。

图注：三张子交换图各画什么

子图 1 · Hom 函子　示意 H = Hom(C,−) 的函子性：箭头 f 被送到后复合 f∘(−)，虚线三角表达 H(g∘f)=H(g)∘H(f)（即结合律），下排逐元素把 idC 送成 f、g∘f。

子图 2 · unit 嵌入　固定 f:A→B 得自然变换 yf : Hom(−,A) ⇒ Hom(−,B)，方块表达其自然性；取 F=Hom(−,B) 即得满忠实 Nat(Hom(−,A),Hom(−,B)) ≅ Hom(A,B)。

子图 3 · corner 构造　核心方块把元素 x = ηC(idC) 与整个 η 连起来：两条路径相等给出 ηxB(f) = F(f)(x)，说明单个元素唯一决定自然变换。
